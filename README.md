# CƯỜNG — Portfolio

Portfolio template for Visual / Motion / 3D work.

## Run locally
Just open `index.html` in a browser.

## Customize
1. Replace the placeholder project areas with your own images/videos.
2. Change `your@email.com` in `index.html`.
3. Update project names and descriptions.
4. Upload the whole folder to GitHub.
5. Enable GitHub Pages from the repository settings.

## Recommended
For large portfolio videos, host the videos externally (for example Vimeo/YouTube or a video CDN) rather than storing large files directly in the Git repository.
